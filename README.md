# Trip Receipts for NBCP: Android download

Trip Receipts is NBCP Communication Systems' app for travel expense reports. This page only hosts the Android app file. The source code is not here.

## Download

**[Download the app (Android)](https://github.com/nicklauspalmer-rgb/trip-receipts-download/releases/latest/download/NBCP-Trip-Receipts.apk)**: about 70 MB.

## Install

1. Tap the download link above on your Android phone. If you're warned the file might be harmful, tap **Download anyway**.
2. Tap the downloaded file. If Android says it can't install unknown apps from this source, tap **Settings**, turn on **Allow from this source**, then go back.
3. Tap **Install**. If Google Play Protect asks, tap **More details**, then **Install anyway**.
4. Open **Trip Receipts** and allow the camera when asked.

To update to a new version, install the new file over the old app. **Don't uninstall first**: your trips and receipts are saved only on your phone, and uninstalling deletes them.

iPhone users install through TestFlight instead: https://testflight.apple.com/join/pFJE6tPv
